# weather-telegram

เฝ้าฟ้า: ดูสภาพอากาศ PM2.5 ฝน UV ของจังหวัดที่คุณอยู่ ทั้งแบบ **เว็บแอป** และ **แจ้งเตือนเข้า Telegram** อัตโนมัติ
ค่าเริ่มต้น: **นครพนม (อ.เมือง)** · ข้อมูลจาก [Open-Meteo](https://open-meteo.com) ไม่ต้องมี API key

```
.
├── docs/                          เว็บแอป (เผยแพร่ด้วย GitHub Pages)
│   ├── index.html
│   ├── manifest.webmanifest       ไฟล์ติดตั้งเป็นแอป (PWA)
│   ├── sw.js                      service worker เปิดแบบออฟไลน์ได้
│   └── icons/
├── telegram/
│   └── weather_alert.py           สคริปต์ส่งสรุปเข้า Telegram
├── scripts/
│   └── air4thai_snapshot.py       เก็บข้อมูล Air4Thai ไว้ให้หน้าเว็บใช้สำรอง
├── .github/workflows/
│   ├── weather.yml                ส่ง Telegram 05:00 11:00 15:00 18:00 21:00 (เวลาไทย)
│   └── air4thai-cache.yml         ดึงข้อมูล Air4Thai ทุก 30 นาที
└── README.md
```

## แหล่งข้อมูล PM2.5

ใช้ค่าจาก**สถานีตรวจวัดจริง** ของกรมควบคุมมลพิษ ([Air4Thai](https://air4thai.pcd.go.th)) เป็นหลัก ซึ่งเป็นค่าเฉลี่ย 24 ชั่วโมง ตรงกับเกณฑ์ที่ใช้ตัดสินระดับ (ดีมาก/ดี/ปานกลาง/เริ่มมีผลต่อสุขภาพ)
ถ้าดึงไม่ได้ จะใช้ค่าจากแบบจำลอง [Open-Meteo](https://open-meteo.com) แทน และแจ้งในหน้าเว็บ/ข้อความว่าเป็นค่าจากแบบจำลอง

- หน้าเว็บ: ดึงจาก Air4Thai ตรง ถ้าไม่ได้ใช้ไฟล์ที่ `air4thai-cache` เก็บไว้ในสาขา `data` ถ้าไม่ได้อีกจึงใช้แบบจำลอง
  เลือกสถานีในจังหวัดที่เลือกที่ใกล้ที่สุด (ถ้าไม่มี ใช้สถานีที่ใกล้ที่สุดภายใน 40 กม.)
- Telegram: ค่าเริ่มต้นใช้สถานี `88t` (ต.ในเมือง อ.เมือง นครพนม) เปลี่ยนได้ด้วยตัวแปร `STATION_ID`
  (ดูรหัสสถานีในหน้า [Air4Thai](https://air4thai.pcd.go.th/webV3/#/Home) กดที่หมุดบนแผนที่)
- เซิร์ฟเวอร์ Air4Thai ส่งใบรับรอง SSL มาไม่ครบสาย workflow จึงดึงใบกลางมาเพิ่มเองก่อน (`scripts/trust_air4thai.sh`) ถ้ายังไม่ผ่าน สคริปต์จะลองแบบไม่ตรวจใบรับรองเป็นทางสุดท้าย และเขียนคำเตือนไว้ใน log (ข้อมูลเป็นค่าคุณภาพอากาศสาธารณะ อ่านอย่างเดียว)
- ครั้งแรกให้ไปที่แท็บ Actions → `air4thai-cache` → Run workflow หนึ่งครั้ง เพื่อสร้างสาขา `data`
  (ใช้ได้เมื่อ repo เป็น public)

## 1) เว็บแอป (`docs/`)

เปิดไฟล์ `docs/index.html` ในเบราว์เซอร์ได้เลย (ติดตั้งเป็นแอปได้เมื่อเปิดผ่าน https เช่น GitHub Pages) หรือเผยแพร่ฟรีด้วย GitHub Pages:
Settings → Pages → Source: *Deploy from a branch* → Branch: `main` โฟลเดอร์ `/docs` → Save
แล้วเข้าที่ `https://jumpot-s.github.io/weather-telegram/`

แสดงอุณหภูมิ, PM2.5/PM10, โอกาสฝน, UV, กราฟ 24 ชม., พยากรณ์ 7 วัน และตั้งเกณฑ์เตือนเองได้
ตั้งเวลาแจ้งเตือนประจำวันเองได้ในหน้า "ตั้งค่าการแจ้งเตือน" (ใช้เวลาไทย UTC+7 เสมอ) แจ้งเตือนบนเบราว์เซอร์ทำงานเฉพาะเมื่อเปิดหน้านี้ค้างไว้ในแท็บ

### ติดตั้งเป็นแอป

เปิดเว็บที่ https://jumpot-s.github.io/weather-telegram/ แล้ว
- Android / Chrome / Edge: กดปุ่ม "ติดตั้งแอป" ที่มุมขวาบน หรือเมนู ⋮ → ติดตั้งแอป
- iPhone / iPad: เปิดใน Safari → ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม

ติดตั้งแล้วเปิดเต็มจอเหมือนแอป และเปิดดูข้อมูลล่าสุดได้แม้ไม่มีอินเทอร์เน็ต

## 2) แจ้งเตือน Telegram (`telegram/` + GitHub Actions)

ข้อความมีอุณหภูมิ, PM2.5, โอกาสฝน 6 ชม., UV, พยากรณ์วันนี้/พรุ่งนี้ และหัวข้อแจ้งเตือนเมื่อค่าเกินเกณฑ์

### ตั้งค่า (ทำครั้งเดียว)

1. **สร้างบอท**: คุยกับ [@BotFather](https://t.me/BotFather) พิมพ์ `/newbot` แล้วเก็บ **token**
2. **หา chat id**: ส่งข้อความหาบอทหนึ่งครั้ง แล้วเปิด
   `https://api.telegram.org/bot<TOKEN>/getUpdates` ดูค่า `"chat":{"id": ...}`
   (ส่งเข้ากลุ่ม: เชิญบอทเข้ากลุ่ม ส่งข้อความในกลุ่ม แล้วดู id ที่ขึ้นต้นด้วย `-`)
3. **ใส่ Secrets** ที่ Settings → Secrets and variables → Actions → *Secrets*
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
4. **ทดสอบ**: แท็บ Actions → `weather-alert` → *Run workflow*

### เปลี่ยนพื้นที่หรือเกณฑ์ (ไม่บังคับ)

ใส่ที่ Settings → Secrets and variables → Actions → *Variables*

| ตัวแปร | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| `STATION_ID` | รหัสสถานี Air4Thai (เว้นว่างเพื่อเลือกสถานีใกล้ LAT/LON ภายใน 30 กม.) | 88t |
| `SEND_TIMES` | เวลาส่ง (เวลาไทย คั่นด้วยจุลภาค) | 05:00,11:00,15:00,18:00,21:00 |
| `PLACE_NAME` | ชื่อที่แสดงในข้อความ | นครพนม (อ.เมือง) |
| `LAT`, `LON` | พิกัด | 17.4105, 104.7783 |
| `PM_THRESHOLD` | เตือนเมื่อ PM2.5 เกิน (µg/m³) | 37.5 |
| `HEAT_THRESHOLD` | เตือนเมื่ออุณหภูมิที่รู้สึกเกิน (°C) | 38 |
| `RAIN_THRESHOLD` | เตือนเมื่อโอกาสฝนใน 6 ชม. ตั้งแต่ (%) | 60 |
| `UV_THRESHOLD` | เตือนเมื่อ UV ตั้งแต่ | 8 |

### เวลาส่งและความตรงเวลา

GitHub Actions มักเริ่มรันช้ากว่า cron หลายนาที workflow นี้จึงเริ่มก่อนเวลาส่ง 15 นาที แล้วสคริปต์รอจนถึงเวลาไทยที่กำหนดก่อนส่งจริง (ถ้าคิวช้าเกิน 15 นาที จะส่งทันทีที่เริ่มรัน)

ถ้าจะเปลี่ยนเวลา ต้องแก้สองที่ให้ตรงกัน:
1. `cron` ใน `.github/workflows/weather.yml` ให้เริ่มก่อนเวลาส่ง 15 นาที เป็นเวลา UTC (เวลาไทย ลบ 7 ชั่วโมง)
2. ตัวแปร `SEND_TIMES` (Variables) เช่น `06:30,12:00,18:00` เป็นเวลาไทย

ตัวอย่าง ส่ง 07:00 ไทย = เริ่มรัน 06:45 ไทย = `45 23 * * *` (UTC ของวันก่อนหน้า)

หมายเหตุ: ถ้า repo เป็น private เวลาที่รอจะนับเป็นนาทีใช้งานของ Actions (เดือนละประมาณ 2,000 นาทีฟรี) repo แบบ public ไม่จำกัด

### ทดสอบในเครื่อง

```bash
DRY_RUN=1 python3 telegram/weather_alert.py
TELEGRAM_BOT_TOKEN=xxx TELEGRAM_CHAT_ID=yyy python3 telegram/weather_alert.py
```

## ข้อควรรู้

- GitHub Actions อาจส่งช้ากว่ากำหนดประมาณ 5–30 นาที
- repo ที่ไม่มีการเคลื่อนไหว 60 วัน GitHub จะหยุด schedule อัตโนมัติ ต้องกดเปิดใหม่ที่แท็บ Actions
- ค่า PM2.5 เป็นค่าจากแบบจำลอง ไม่ใช่เครื่องวัดจริง ควรเทียบกับ Air4Thai
