    แหล่งข้อมูลอุณหภูมิ

    อุณหภูมิในแอปมาจากแบบจำลองคอมพิวเตอร์ ไม่ใช่ค่าที่วัดจริง แต่ละแบบจำลองให้ค่าไม่เท่ากัน ถ้าตัวเลขต่างจากแอปสภาพอากาศในเครื่องของคุณ ให้กดเทียบ แล้วเลือกแบบจำลองที่ใกล้ที่สุด

    เวลาแจ้งเตือนประจำวัน (เวลาไทย UTC+7)

    ติดตั้งเป็นแอป

    Android, Chrome, Edge: กดปุ่มติดตั้ง หรือเมนู ⋮ แล้วเลือก "ติดตั้งแอป" ส่วน iPhone: เปิดใน Safari กดปุ่มแชร์ แล้วเลือก "เพิ่มไปยังหน้าจอโฮม" เมื่อติดตั้งแล้วเปิดได้เต็มจอเหมือนแอป และเปิดดูข้อมูลล่าสุดได้แม้ไม่มีอินเทอร์เน็ต

    เบราว์เซอร์จะส่งสรุปตามเวลาที่ตั้งไว้ (ตามเวลาไทยเสมอ) และเตือนทันทีเมื่อค่าเกินเกณฑ์ ใช้ได้เฉพาะเมื่อเปิดหน้านี้ค้างไว้ในแท็บ หากต้องการเตือนขณะปิดหน้า ให้ใช้ Telegram ที่ตั้งไว้ใน GitHub Actions
